One share. Your answer, gathered.

Set this up once on your iPhone. Then share a ChatGPT answer to a shortcut: Safari opens briefly, and Gather receives the Markdown automatically.

ChatGPT Share → Gather Auto → choose your blocks.
No second Share menu. No clipboard or Paste step.

1. Install Userscripts

Get Userscripts
  1. Open Userscripts once. Keep its default script folder.
  2. Enable Userscripts in Settings → Apps → Safari → Extensions.
  3. Open chatgpt.com in Safari. In the page menu → Extensions → Userscripts, allow it on this website. Do the same for Gather.

Open Gather in Safari and sign in before your first transfer. Safari must be the browser your shortcut opens.

2. Install Gather Auto

Open this script in Safari, then open Safari’s page menu → Extensions → Userscripts → Install.

Open Gather Auto script Download instead

If no install prompt appears, download gather-auto.user.js and move it into the script folder shown by the Userscripts app. Then open the Userscripts extension menu once so it detects the file.

3. Create a shortcut: Gather Auto

In Shortcuts, create a new shortcut called Gather Auto. Enable Show in Share Sheet and accept URLs and Text.

Add these actions in order:

ActionInput
Get URLs from InputShortcut Input
Get Item from ListFirst Item from URLs
URLx-safari-Item from List#gather-auto
Open URLsURL from the preceding action

Blue labels above are variables: select them from an earlier action’s output. In the URL action, type x-safari-, insert the blue Item from List variable, then type #gather-auto. Do not add spaces. The result should look like x-safari-https://chatgpt.com/s/…#gather-auto.

The x-safari- prefix requests Safari explicitly. An ordinary HTTPS link may open back inside the ChatGPT app, where Userscripts cannot run. If iOS asks to open Safari, allow it.

Keep your original Send to Gather shortcut as a fallback. This new shortcut has no Run JavaScript on Webpage action.

Try it

In ChatGPT, share an answer and choose Gather Auto. Wait for the answer to load in Safari. Gather should open in Select blocks mode, ready to tap.

If you already had a draft, Undo import restores it and its selections until another edit or reload.

If it stops along the way
  • Safari opens, then nothing: confirm the address ends with #gather-auto, and Userscripts is enabled and allowed on chatgpt.com.
  • Gather opens but no answer: allow Userscripts on Gather too. Reload the page while its #gather-transfer=… fragment remains.
  • A sign-in or page check appears: finish it manually, then use Retry if shown. If the fragment was lost, share the answer again.
  • The ChatGPT app or another browser opens: check that the URL action starts with the literal x-safari- before the blue Item from List variable. Its output must go directly to Open URLs; do not extract HTTPS links from it again.

Gather Auto reads the last displayed answer. Only links marked by your shortcut trigger sending. The text passes through local extension storage and is removed after a successful handoff; it is not placed in the URL or sent to an extraction service. Unfinished transfers expire after one hour.

This is an experimental iPhone workflow. Initial extension permissions and sign-in may need your taps.
